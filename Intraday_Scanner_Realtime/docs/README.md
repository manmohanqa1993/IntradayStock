# 📊 Intraday Scanner Realtime - Multi-Broker

**Real-time scanner with multi-broker support**

---

## ⚡ Supported Brokers

- 🆓 FREE (Hybrid NSE+Yahoo)
- 🔴 Zerodha Kite
- 🔵 Angel One
- 🟢 Upstox
- 🟡 Fyers

---

## 🚀 Quick Start

```bash
cd Intraday_Scanner_Realtime
batch\setup.bat
# Edit config/settings.py - choose broker
batch\run.bat
```
