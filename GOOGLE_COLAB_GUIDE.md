## 🎯 Step-by-Step Instructions

### Step 1: Upload Notebook to Google Colab

**Option A: Direct Upload (Easiest)**

1. Go to: https://colab.research.google.com/
2. Click **"File"** → **"Upload notebook"**
3. Click **"Choose File"**
4. Select: `NSE_Intraday_Scanner_Colab.ipynb` (from your Desktop\stock folder)
5. Wait for upload to complete (5-10 seconds)
6. Done! Notebook is ready ✅

**Option B: Upload to Google Drive First**

1. Go to: https://drive.google.com
2. Create a folder: "Stock Scanner"
3. Upload `NSE_Intraday_Scanner_Colab.ipynb` to this folder
4. Right-click the file → **"Open with"** → **"Google Colaboratory"**
5. Done! ✅

---

### Step 2: Run the Scanner

**Method 1: Run Everything at Once (Recommended)**

1. In Google Colab, click **"Runtime"** (top menu)
2. Click **"Run all"**
3. Wait 2-3 minutes while it:
   - Installs packages
   - Scans 50+ stocks
   - Shows results
4. Scroll down to see results! 📊

**Method 2: Run Step by Step**

1. Click the **▶️ Play button** on the left of each code cell
2. Start from top, run each cell one by one
3. Wait for each cell to finish (green checkmark ✅)
4. Continue to next cell

## ⚠️ Troubleshooting

### "Runtime disconnected"
- Colab disconnects after 90 min of inactivity
- Just click **"Reconnect"** and run again
- Your notebook is saved!

### "No stocks found"
- Market may be range-bound
- Try scanning at different times
- Criteria might be too strict (normal)

### "Module not found" error
- Run **Step 1** (Install packages) first
- Always run cells in order from top

### Slow scanning
- Normal! Scanning 50+ stocks takes 2-3 minutes
- Google Colab is free, so it's not super fast
- But it works perfectly!

### "Quota exceeded"
- Free Colab has usage limits
- Wait a few hours and try again
- Or upgrade to Colab Pro (₹800/month) - not needed!
